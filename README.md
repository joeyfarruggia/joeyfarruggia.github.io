# Joey Farruggia | Software Developer Portfolio

My personal software development portfolio, built with HTML, CSS, and JavaScript and deployed with GitHub Pages.

🌐 **Live Portfolio:** [joeyfarruggia.github.io](https://joeyfarruggia.github.io)

## Overview

This website serves as my personal developer portfolio and a central place to showcase my background, technical skills, and software-development projects.

I originally created the portfolio while attending The Tech Academy and have continued updating it as my skills and project experience have grown.

The site includes information about my development background, links to my GitHub projects, interactive front-end features, and a working contact form for anyone interested in connecting with me.

## Features

- Deployed publicly with GitHub Pages
- Custom HTML, CSS, and JavaScript
- Full-screen background video
- Interactive image slideshow
- Navigation between portfolio sections
- About Me section
- GitHub project showcase
- Featured Python Study Assistant ChatBot project
- Interactive popup contact form
- Contact form submission through Formspree
- Mobile-friendly viewport configuration
- Custom styling and visual effects

## Featured Project

### Python Study Assistant ChatBot

My portfolio currently highlights my **Python Study Assistant ChatBot**, developed during my Live Project at The Tech Academy.

The project demonstrates:

- Rule-Based and NLP chatbot engines
- Python and NLTK
- Naive Bayes intent classification
- Tkinter desktop interface
- Responsive browser interface
- Automated testing
- Confidence-aware fallback behavior
- Git, branching, pull requests, and Azure DevOps workflows
